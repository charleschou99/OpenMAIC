# 义教AI教室 - 志愿者快速开始指南

欢迎加入义教AI教室项目！本指南将帮助您快速上手使用课件生成和管理工具。

## 🎯 项目简介

义教AI教室是一个为中国农村小学生提供AI辅助教育的开源项目。我们使用AI技术预先生成高质量的课件，让志愿者可以专注于人文关怀和个性化指导。

**核心功能：**
- 📚 课件批量生成（基于人教版等教材）
- ✅ 内容安全审核
- 👀 人工审核流程
- 📦 离线课件导出
- 📊 学习进度追踪

## 📋 系统要求

- Node.js >= 22.19
- pnpm >= 10
- PostgreSQL 16（用于主服务）
- 可选：DeepSeek/Qwen API密钥（用于真实生成）

## 🚀 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/charleschou99/OpenMAIC.git
cd OpenMAIC
pnpm install
```

### 2. 配置环境

```bash
# 复制配置文件
cp .env.example .env.local
cp openmaic.example.yml openmaic.yml

# 编辑 .env.local，设置数据库连接
# DATABASE_URL=postgres://openmaic:openmaic-dev@127.0.0.1:5432/openmaic
```

### 3. 启动数据库和服务

```bash
# 启动 PostgreSQL（如果使用 Docker）
pnpm db:up

# 启动开发服务器
pnpm dev
```

服务启动后访问：
- 主应用：http://127.0.0.1:3000
- 志愿者面板：http://127.0.0.1:3000/volunteer

## 🛠 使用 Pack Builder CLI

Pack Builder 是课件包管理的命令行工具。

### 基本命令

```bash
# 进入 pack-builder 目录
cd pack-builder

# 安装依赖
pnpm install

# 使用 tsx 直接运行（开发模式）
pnpm dev <命令>
```

### 1. 初始化课件包

从课程清单创建课件包：

```bash
pnpm dev init ../curriculum/一年级/数学/manifest.yml
```

### 2. 生成课件（模拟模式）

在没有API密钥时使用模拟数据测试：

```bash
pnpm dev generate ../curriculum/一年级/数学/unit-1 --mock
```

使用真实API生成（需要配置密钥）：

```bash
# 在 .env.local 中设置 DEEPSEEK_API_KEY 或 QWEN_API_KEY
pnpm dev generate ../curriculum/一年级/数学/unit-1 --real
```

### 3. 安全检查

运行内容安全过滤器：

```bash
pnpm dev safety ../curriculum/一年级/数学/unit-1
```

### 4. 审核流程

```bash
# 开始审核
pnpm dev review ../curriculum/一年级/数学/unit-1 --start -r 志愿者A

# 提交审核意见
pnpm dev review ../curriculum/一年级/数学/unit-1 --submit -r 志愿者A -c "内容适合一年级学生"

# 批准发布
pnpm dev review ../curriculum/一年级/数学/unit-1 --approve -r 志愿者A

# 查看状态
pnpm dev status ../curriculum/一年级/数学/
```

### 5. 导出离线课件

```bash
# 导出为USB包（用于离线分发）
pnpm dev export ../curriculum/一年级/数学/unit-1 -o ./exports -f usb-bundle

# 导出为 .maic.zip 文件
pnpm dev export ../curriculum/一年级/数学/unit-1 -o ./exports -f maic-zip
```

## 📊 使用志愿者面板

访问 http://127.0.0.1:3000/volunteer

### 审核队列

1. 点击"审核队列"标签
2. 选择待审核的课件包
3. 查看课件内容和安全检查状态
4. 添加审核意见
5. 点击"批准发布"或"拒绝"

### 学习进度

1. 点击"学习进度"标签
2. 选择课件单元
3. 查看学生完成情况和分数
4. 点击学生查看详细进度

## ⚠️ 注意事项

1. **内容安全**：所有AI生成的内容必须经过安全检查和人工审核后才能分发
2. **隐私保护**：学生数据使用匿名标签（学生A、学生B），不收集真实个人信息
3. **离线优先**：课件设计为离线可用，无需网络连接即可播放

## 🆘 常见问题

**Q: 没有API密钥怎么测试？**
A: 使用 `--mock` 参数进行模拟生成，会使用示例数据。

**Q: 安全检查报错怎么办？**
A: 检查 `safety` 命令的输出，修改有问题的内容后重新运行检查。

**Q: 如何分发课件到学校？**
A: 使用 `export` 命令导出USB包，复制到U盘或SD卡即可。
