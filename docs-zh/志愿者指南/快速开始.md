# 义教AI教室 - 志愿者快速开始指南

欢迎加入义教AI教室项目！本指南将帮助您快速上手使用课件生成和管理工具。

## 🎯 项目简介

义教AI教室是一个为中国农村小学生提供AI辅助教育的开源项目。我们使用AI技术预先生成高质量的课件，让志愿者可以专注于人文关怀和个性化指导。

**核心功能：**
- 📚 课件批量生成（基于人教版、统编版等教材）
- ✅ 内容安全审核
- 👀 人工审核流程
- 📦 离线课件导出
- 📊 学习进度追踪

## 📋 系统要求

- Node.js >= 22.19
- pnpm >= 10
- DeepSeek API密钥（用于生成课件）

## 🚀 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/charleschou99/OpenMAIC.git
cd OpenMAIC
pnpm install
```

### 2. 配置 DeepSeek API

```bash
# 在项目根目录创建 .env.local
cp pack-builder/.env.example .env.local

# 编辑 .env.local，填入您的 API 密钥
# DEEPSEEK_API_KEY=your-deepseek-api-key-here
```

**获取 DeepSeek API 密钥：**
1. 访问 https://platform.deepseek.com/
2. 注册/登录账户
3. 在 API Keys 页面创建新密钥
4. 复制密钥到 .env.local

**费用说明（2024年价格）：**
- 单节课生成成本：约 ¥0.02 人民币
- 单个单元（8课）：约 ¥0.17 人民币
- 整学期（40课）：约 ¥0.86 人民币

## 🛠 使用 Pack Builder CLI

Pack Builder 是课件包管理的命令行工具。

### 基本命令

```bash
cd pack-builder
pnpm dev <命令>
```

### 1. 估算生成成本（不需要API密钥）

先用 `--dry-run` 估算成本：

```bash
# 估算一年级数学第一单元的生成成本
pnpm dev generate ../curriculum/一年级/数学/上学期/unit-1 --dry-run

# 输出示例：
# 📊 Cost Estimate (Dry Run)
# Cost Estimate for 2 lesson(s):
#   Model: deepseek-chat
#   Estimated cost: $0.0046 USD (¥0.03 CNY)
```

### 2. 生成真实课件（需要API密钥）

```bash
# 使用 DeepSeek 生成课件
pnpm dev generate ../curriculum/一年级/数学/上学期/unit-1 --real --provider deepseek

# 指定模型
pnpm dev generate ../curriculum/一年级/数学/上学期/unit-1 --real --provider deepseek --model deepseek-chat
```

### 3. 测试模式（不需要API密钥）

```bash
# 使用模拟数据测试流程
pnpm dev generate ../curriculum/一年级/数学/上学期/unit-1 --mock --fixtures ./test/fixtures
```

### 4. 安全检查

```bash
pnpm dev safety ../curriculum/一年级/数学/上学期/unit-1
```

### 5. 审核流程

```bash
# 开始审核
pnpm dev review ../curriculum/一年级/数学/上学期/unit-1 --start -r 志愿者A

# 提交审核意见
pnpm dev review ../curriculum/一年级/数学/上学期/unit-1 --submit -r 志愿者A -c "内容适合学生"

# 批准发布
pnpm dev review ../curriculum/一年级/数学/上学期/unit-1 --approve -r 志愿者A
```

### 6. 导出离线课件

```bash
# 导出为USB包（用于离线分发）
pnpm dev export ../curriculum/一年级/数学/上学期/unit-1 -o ../exports --workspace-root /path/to/OpenMAIC
```

## 📊 完整生成流程示例

以一年级数学第一单元为例：

```bash
cd pack-builder

# 1. 估算成本
pnpm dev generate ../curriculum/一年级/数学/上学期/unit-1 --dry-run

# 2. 确认后生成（需要 DEEPSEEK_API_KEY）
pnpm dev generate ../curriculum/一年级/数学/上学期/unit-1 --real --provider deepseek

# 3. 安全检查
pnpm dev safety ../curriculum/一年级/数学/上学期/unit-1

# 4. 审核批准
pnpm dev review ../curriculum/一年级/数学/上学期/unit-1 --start -r 我的名字
pnpm dev review ../curriculum/一年级/数学/上学期/unit-1 --submit -r 我的名字 -c "检查完成，内容合适"
pnpm dev review ../curriculum/一年级/数学/上学期/unit-1 --approve -r 我的名字

# 5. 导出离线包
pnpm dev export ../curriculum/一年级/数学/上学期/unit-1 -o ../exports --workspace-root ..

# 6. 查看状态
pnpm dev status ../curriculum/一年级/数学/上学期/
```

## 📁 课程目录结构

```
curriculum/
├── subjects.yml                 # 学科定义（教材版本等）
├── 一年级/
│   ├── 语文/（统编版）
│   ├── 数学/（人教版）
│   ├── 道德与法治/（统编版）
│   └── 科学/（教科版）
├── 二年级/
│   └── ...
├── 三年级/
│   ├── 英语/（人教版 PEP，三年级开始）
│   └── ...
└── ...（四至六年级）
```

每个学科目录包含：
- `上学期/manifest.yml` - 上册课程清单
- `下学期/manifest.yml` - 下册课程清单
- `*/unit-*/pack.yml` - 各单元课件包

## ⚠️ 注意事项

1. **内容安全**：所有AI生成的内容必须经过安全检查和人工审核后才能分发
2. **隐私保护**：学生数据使用匿名标签，不收集真实个人信息
3. **离线优先**：课件设计为离线可用，无需网络连接即可播放
4. **教材版本**：
   - 语文、道德与法治：统编版/部编版
   - 数学：人教版
   - 英语：人教版 PEP（三年级起）
   - 科学：教科版（可配置其他版本）

## 🆘 常见问题

**Q: API密钥报错怎么办？**
A: 确保 `.env.local` 中的 `DEEPSEEK_API_KEY` 正确设置，没有多余空格。

**Q: 安全检查报错怎么办？**
A: 检查 `safety` 命令输出，修改有问题的内容后重新运行检查。

**Q: 如何分发课件到学校？**
A: 使用 `export` 命令导出USB包，复制到U盘或SD卡即可。

**Q: 生成失败或中断怎么办？**
A: 重新运行 `generate` 命令，已生成的内容会被覆盖。
